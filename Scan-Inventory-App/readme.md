Scan Inventory App

Aplikacja mobilna do zarządzania inwentarzem produktów z funkcją skanowania zdjęć.

Funkcjonalności
Lista Produktów - Przeglądanie wszystkich produktów z kodem i statusem
Szczegóły Produktu - Wyświetlanie pełnych informacji o produkcie
Dodawanie Produktów - Formularz z walidacją i możliwością dodania zdjęcia
Aparat/Galeria - Możliwość zrobienia zdjęcia lub wybrania z galerii
Usuwanie Produktów - Możliwość usunięcia produktu z listy
Tryb Offline - Przełącznik trybu offline w ustawieniach
Responsywny Design - Dostosowany do ekranów mobilnych
Technologia

Framework: NativeScript + Angular 17
Język: TypeScript
API: JSONPlaceholder (testowe)
Platforma: Android/iOS
Node.js: 18+ LTS

Wymagania
Przed rozpoczęciem upewnij się, że masz zainstalowane:

Node.js 18+ - https://nodejs.org/
npm 9+ - Zainstaluje się automatycznie z Node.js
NativeScript CLI - npm install -g @nativescript/cli
Android SDK (dla Android) lub Xcode (dla iOS)

Instalacja i Uruchomienie

1. Instalacja Zależności
   bashcd Scan-Inventory-App
   npm install
2. Uruchomienie na Android
   bashns run android
3. Uruchomienie na iOS (macOS)
   bashns run ios
4. Preview w Przeglądarce
   bashns preview
